# SharePoker 登录系统使用说明

## 功能概述

为了保护demo和index页面的访问，系统现在需要用户登录才能访问这些页面。

## 登录信息

- **账号**: admin
- **密码**: admin123

## 使用方法

### 1. 访问登录页面

当用户直接访问 `demo.html` 或 `index.html` 时，系统会自动重定向到登录页面 `login.html`。

### 2. 输入账号密码

在登录页面输入：
- 账号：admin
- 密码：admin123

### 3. 登录成功

登录成功后，系统会自动跳转到用户原本要访问的页面。

### 4. 退出登录

在页面右上角有"退出登录"按钮，点击后会清除登录状态并返回登录页面。

## 安全特性

- 登录状态使用localStorage存储
- 登录状态有效期为24小时
- 超过有效期后需要重新登录
- 支持回车键快速登录

## 文件说明

- `login.html` - 登录页面
- `index.html` - 主页面（需要登录）
- `demo.html` - 演示页面（需要登录）

## 注意事项

- 账号密码是硬编码的，仅用于演示
- 在生产环境中应该使用更安全的认证方式
- 登录状态存储在浏览器本地，清除浏览器数据会丢失登录状态
